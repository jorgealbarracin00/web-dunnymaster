# DunnyMaster website

Public product, support, and privacy pages for DunnyMaster by Gama Dynamics.

- Production: <https://dunnymaster.gamadynamics.com.au>
- Support: <https://dunnymaster.gamadynamics.com.au/support>
- Privacy: <https://dunnymaster.gamadynamics.com.au/privacy>

The site is a dependency-free static deployment. Vercel serves the `dist` directory as configured in `vercel.json`.
